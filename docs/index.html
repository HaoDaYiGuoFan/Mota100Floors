一、项目简介

《魔塔 100 层》是一款致敬经典《魔塔》玩法的单机回合制爬塔 RPG，使用 .NET 10 + WPF 实现， 以「原版剧情 + 经典交互 + 数值化战斗」为设计核心。玩家控制勇者，在一座 100 层的魔塔中拾取道具、 击杀怪物、开启门锁、与 NPC 对话并接受任务，最终登顶击败魔王·加坦杰厄。

本 GDD 站点将「原版剧情」与「战斗/交互规则」固化为可读文档，并同步描述当前版本已实现的全部内容。 所有数值均可对应到游戏数据文件（Data/*.json）。

三、版本亮点（v1.0 明亮版）

  • 经典美术换皮：原版《魔塔》风格素材全部接入 —— 四方向勇者、6 类经典怪物贴图、三色门 / 钥匙、楼梯 / 商店 / NPC / 宝石 / 血瓶，地图由占位色块全面替换。
  • 音效与朝向动画：拾取道具、战斗命中均带音效；勇者按移动方向实时切换四方向贴图。
  • 法师怪无视防御：6 种魔法系怪物（闪电法师 / 水晶灵体 / 邪眼魔 / 混沌魔裔 / 暗影主宰 / 魔神）攻击不扣玩家防御，战斗预估与怪物手册同步修正。
  • 明亮开局 UI：暖阳渐变窗口底色、奶油金 HUD、金色圆角按钮（悬浮/按压反馈）、高对比文字。
  • 魔塔式战斗：无伤判定 / 预损提示（回合数 + 每回合伤害），打不过时自动放弃并给出建议。
  • 进度门槛：全塔 6 处守门 NPC，以攻击力 / 防御力作为通行条件（详见「交互规则」）。
  • 剧情任务：5 个可接取任务（抵达层数 / 击杀 / 拾取三种目标），带进度与奖励，随档保存。
  • 原版剧情感：新增/强化 20+ 处层内 NPC 剧情对话，串联「勇者登塔 · 魔王封印」主线。
