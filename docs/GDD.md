## 1. 目标

在保留"数值即一切"的经典魔塔内核之上，将遭遇战升级为**玩家可见、可抉择、逐回合推进**的战斗系统：

- 走上怪物格**弹出战斗面板**，先展示预演战果，再让玩家选择「战斗 / 撤退」；
- 战斗**逐回合演示**（每回合玩家先手 → 怪物反击 → 吸血回复），实时刷新双方生命；
- 引入 **4 类怪物**（普通 / 魔法固定伤害 / 吸血 / BOSS），各自具有差异化行为与对局提示；
- **破防门槛**：攻击不足以破防时禁止开战，杜绝"刮痧送死"；
- **BOSS 战**：禁止撤退、胜利掉落红钥匙 ×1，第 100 层 BOSS 被击败即通关。

## 2. 战斗流程

```
走上怪物格
   │
   ▼
阶段① 遭遇：弹出战斗面板，显示怪物名/类型/属性、玩家属性、
│       预估损失与胜负判定（数值层与真实战斗共用同一公式）
│
阶段② 抉择：玩家选择「⚔ 战斗」或「撤退」
│        ├─ 撤退（仅非 BOSS）：立即关闭面板，不扣血、无奖励，玩家留在原地
│        └─ 战斗：先校验破防（玩家攻击 > 怪物防御），否则禁止开战并取消面板
│
阶段③ 逐回合：每回合玩家先手造成伤害 → 若怪物存活则怪物反击 →
│        吸血怪回复等量生命；回合战报滚动记录，双方 HP 实时刷新
│
阶段④ 结算：胜利 → 奖励金币 + 击杀计数 + 怪格变地板 + 玩家移动到该格；
│         BOSS 额外掉落红钥匙 ×1（第 100 层 → 通关）
│        失败 → 玩家生命归零、阵亡、重新开始
```

## 3. 怪物类型（4 类）

| 类型 | 标识 | 行为 | 战斗面板标注 |
|---|---|---|---|
| 普通 | `Normal` | 标准回合制，攻防公式结算 | 普通怪 |
| 魔法·固定伤害 | `FixedDamage` | 每回合造成 `max(1, 攻击力)` 直伤，**无视玩家防御** | 魔法怪 · 固定伤害 · 无视防御 |
| 吸血 | `DrainBlood` | 每次成功反击后回复等量生命（上限为怪物初始生命） | 吸血怪 · 反击后回复生命 |
| BOSS | `Boss` | 禁止撤退；胜利掉落红钥匙 ×1；第 100 层 BOSS 胜利即通关 | BOSS · 禁止撤退 · 掉落红钥匙 |

## 4. 数值公式

```
玩家每回合伤害 = max(1, 玩家攻击 − 怪物防御)
怪物每回合伤害 = max(1, 怪物攻击 − 玩家防御)      // 魔法·固定伤害型：= max(1, 怪物攻击)
击杀所需回合数 = ⌈怪物生命 ÷ 玩家每回合伤害⌉
预估损失生命   = (击杀回合数 − 1) × 怪物每回合伤害  // 最后一回合怪物已被击杀，不反击
吸血回复量     = min(本回合反击伤害, 怪物初始生命 − 怪物当前生命)
```

预估（`SimulateBattle`）与真实逐回合（`StepBattle`）共用同一套公式，保证"手册说的"就是"实战发生的"。

## 5. 破防规则

- 玩家攻击 ≤ 怪物防御 ⇒ **无法破防**，点击「战斗」被拒绝：不触发战斗、不损失生命，仅提示"提升攻击后再来"，面板随即关闭。
- 破防成功才允许开战；防御压制依然有效（高防御可把承伤压到 `1`）。

## 6. 撤退规则

- 非 BOSS 战可选「撤退」：立即结束，不扣血、无奖励，玩家留在原格，可练级后再战。
- **BOSS 战禁止撤退**（撤退按钮禁用）。

## 7. BOSS 战

- 每层主 BOSS 胜利后掉落 **红钥匙 ×1**（用于开启更深处红门）。
- 第 100 层最终 BOSS「魔王·加坦杰厄」（模板 Id 41）被击败 ⇒ `Player.IsWin = true` ⇒ 通关结算。

## 9. UI 呈现

- 战斗面板（`BattleOverlay`）：怪物卡（贴图/名/类型/属性/实时 HP）＋ 勇士卡（实时 HP/攻/防）＋ 预估战损警告行 ＋ 逐回合战报日志 ＋ 操作按钮。
- 必死预警：预估损失 ≥ 当前生命时显示「⚠ 此战必死」。
- 战斗中锁定方向键 / 存档 / 读档 / 静音 / 手册等全局操作，直至结算完成。
