交互规则

移动 · 钥匙门 · 道具 · 商店 · NPC · 守门门槛 · 任务系统 · 存档

一、移动与地形

  • 地图为 18 × 11 的网格，每格 48 × 48 像素；方向键或 WASD 每按一次移动一格。
  • 勇者移动时按方向实时切换四方向朝向贴图（↑ / ↓ / ← / → 各自独立素材），撞墙不转向。
  • 墙「W」不可通行；地板「.」可通行。
  • 上楼「U」进入上一层；下楼「D」进入下一层。第 1 层无下路、第 100 层无上路。
  • 楼层之间存在「回廊互通」：打不过的怪物可以绕行，先变强再回来。
进入新楼的落点：从下层上楼落在该层 D 处；从上层下楼落在该层 U 处；开局/读档落点由出生点或存档坐标决定。

二、钥匙与门

门所需钥匙说明
黄门「y」黄钥匙最常见，每把开门消耗 1
蓝门「b」蓝钥匙中后期通道，较稀缺
红门「r」红钥匙高阶区域，全塔极少

钥匙从道具（key_*）拾取或商店购买。开门必须消耗 1 把对应钥匙； 钥匙不足时系统提示「没有 XX钥匙，无法开门」并原地停留。

已经打开的门会永久变为地板；存档后读档仍保持打开状态（以 “x,y” 坐标增量记录）。

三、道具拾取

类型效果
生命药水（小 / 大 / 圣光）回复 100 / 300 / 1000 点生命（不超过上限）
力量宝石（小 / 大 / 战神之石）攻击 +5 / +15 / +40
守护宝石（小 / 大 / 泰坦之盾）防御 +5 / +15 / +40
钥匙（黄 / 蓝 / 红）对应钥匙 +1

走上道具格自动拾取并立即生效，同时刷新 HUD 与消息（伴随拾取音效）；拾取状态随档保存。

四、商店

塔中共有 15 座商店（第 2 / 5 / 10 / 20 / 25 / 32 / 40 / 55 / 62 / 70 / 78 / 85 / 90 / 95 / 99 层），店主均为「旅行商人」，使用金币购买。

商品效果价格
生命 +300立即回复 300 生命（受上限约束）200 金
攻击 +10永久攻击 +10400 金
防御 +10永久防御 +10400 金
黄钥匙 +1 / 蓝钥匙 +1 / 红钥匙 +1对应钥匙 +150 / 100 / 200 金

金币不足时无法购买；Esc 关闭商店，商店中不可存档。

五、NPC 对话

走上 NPC 格自动触发对话，对话内容写入右侧「事件记录」。NPC 分为三类：

  • 剧情 NPC：提供世界观、提示与预言（如老祭司、贤者、先知）。
  • 任务 NPC：接受并交付任务（见「任务系统」）。
  • 守门 NPC：以属性门槛拦路，条件不足无法通过（见下）。
地图悬停 NPC 可见其名字、台词；守门 NPC 额外显示「守门条件」；任务 NPC 显示关联任务名。

六、守门 NPC（魔塔式进度门槛）

守门 NPC 站在必经之路上，是经典魔塔的「属性门槛」机制。玩家尝试走上守门格时：

  • 条件不满足 → NPC 拦下并提示所需条件，玩家原地停留，不消耗任何资源；
  • 条件满足 → NPC 放行（播放放行台词），玩家正常走到该格。
支持的条件类型：攻击力 ≥ V / 防御力 ≥ V / 金币 ≥ V / 红·蓝·黄钥匙 ≥ V（只检测不消耗）/ 抵达层数 ≥ V

全塔布防 6 处守门 NPC，作为爬塔节奏的「阶段验收」：

楼层守卫通行条件关卡意义
5石像鬼守卫攻击力 ≥ 45初入回廊的破防验收（幽灵/骷髅兵之后）
10魔法屏障守卫防御力 ≥ 105检验对铁甲骑士等高攻怪的承伤能力
20烈焰石像攻击力 ≥ 190中层要塞入口，需能破石魔像之防
50深渊之门守卫防御力 ≥ 300深渊回廊的准入线
80钢铁守门人防御力 ≥ 800神魔战场兵械库，抵御冰霜巨龙冲击
90末日之门守卫攻击力 ≥ 1000神魔战场大门，需能击破上古石像

守门条件均可在当前阶段通过「拾取属性宝石 + 商店强化 + 折返下层」达成；商店可在关键节点提供攻/防补给，避免卡关。

七、任务系统

与任务 NPC 对话即自动接取任务；达成目标后回到该 NPC 对话交付并领取奖励。任务状态： 0 未接取 → 1 进行中 → 2 已完成，随存档保存。

任务来源 NPC（楼层）目标奖励
初入魔塔老祭司（1）抵达第 3 层金币 30 · 攻击 +3
幽灵之患狩猎队长（5）击杀 3 只幽灵（模板 4）金币 50 · 攻击 +5
生命之泉药师（10）拾取 5 瓶生命药水·小（模板 1）生命上限 +200
铁甲之壁铁甲队长（20）击杀 2 名铁甲骑士（模板 10）金币 120 · 防御 +10
深渊守望深渊守望者（50）抵达第 50 层金币 500 · 攻击 +20 · 防御 +20
  • 击杀统计：击杀怪物按「模板 ID」累计（KillByTemplate），任务进度实时显示「2/3」；
  • 拾取统计：拾取道具同样按模板累计（PickByTemplate）；
  • 抵达统计：以玩家当前楼层判定，到达目标层即可交付；
  • 任务交付后不会重复发放奖励；已完成的任务 NPC 会显示感谢语。

八、存档与读档

  • F5 存档：写入 %LOCALAPPDATA%\Mota100Floors\save.json（临时文件 + 原子覆盖，防损坏）；
  • F9 读档：恢复玩家属性、当前楼层与坐标、怪物存活、道具拾取、已开门（增量）、任务状态与击杀/拾取统计；
  • 存档为「增量合并」语义：怪物复生（重新存活）后再次存档，会从死亡清单中移除该条目；
  • 损坏或更高版本的存档会被拒绝读取（返回「未找到有效存档」）。

九、怪物手册（B 键）

任意时刻按 B（或点击顶部「怪物手册 B」按钮）打开手册，列出全部 41 种怪物的 生命 / 攻击 / 防御 / 金币 / 素材贴图，并实时计算当前预估损失与可战胜判定：

  • 预估损失 = 击杀所需回合数 × 怪物每回合伤害，与 战斗规则公式一致，所见即所得；
  • 法师系怪物标注「魔法·无视防御」，其伤害直接等于攻击力、不扣除防御；
  • 「✓ 可战胜」绿色 /「✗ 暂不可战胜」红色，随角色属性实时刷新；再次按 B、按 Esc 或点「关闭」退出。
