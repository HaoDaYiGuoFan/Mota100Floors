战斗规则

回合制伤害公式 · 无伤判定 · 自动结算 · 41 种怪物全数据

一、伤害公式

战斗为自动回合制：走上怪物格即开始结算，玩家先手。双方每回合各攻击一次， 直至一方生命归零；怪物不回复、无特殊技能，数值即一切。

玩家每回合伤害 = max(1, 玩家攻击 − 怪物防御)
怪物每回合伤害 = max(1, 怪物攻击 − 玩家防御)
击杀所需回合数 = ⌈怪物生命 ÷ 玩家每回合伤害⌉
预估总损失 = 回合数 × 怪物每回合伤害
  • 攻击 ≤ 怪物防御时，玩家伤害仍保底为 1（可磨死但回合数极长，不推荐）；
  • 怪物攻击 ≤ 玩家防御时，怪物伤害同样保底 1；
  • 生命上限只影响拾取/商店回血的封顶值，不影响战斗伤害结算。
法师系怪物无视玩家防御：闪电法师（#18）、水晶灵体（#24）、邪眼魔（#25）、混沌魔裔（#32）、暗影主宰（#35）、魔神（#40）的每回合伤害不扣除玩家防御，直接等于其攻击力（保底 1）。战斗预估与怪物手册均按此计算，无任何随机量。

二、自动结算与无伤判定

  1. 走上怪物格 → 引擎计算「回合数 / 每回合伤害 / 预估总损失」并先做预算；
  2. 打不过（预估总损失 ≥ 当前生命）→ 放弃战斗，玩家原地停留，提示「需 N 回合、每回合损失 M… 提升攻击/防御后再来」；
  3. 打得过 → 扣除预估伤害、获得金币、怪物标记死亡、统计击杀（KillByTemplate）、格子变为地板；
  4. 当前楼层为 100 且击败 BOSS → 置 胜利状态（IsWin）；
  5. 战斗消息展示「耗时 N 回合，损失 X 生命，获得 Y 金币」，玩家属性同步刷新。
预估采用「理论伤害」，即所有回合造成的伤害线性累加，与实际回合制完全一致——不存在暴击/闪避等随机量，结果可精确预测。
