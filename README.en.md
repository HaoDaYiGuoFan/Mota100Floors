## 🆕 V1.1 · Reworked to Match the Original Mota

## ✨ Features

- **100-floor dungeon**: 18×11 grid, 48 px tiles; stairs, three-color key doors and interlinked corridors — take detours to grow stronger before harder fights.
- **Fully aligned with the original Mota (V1.1 stat rework)**: 60 monsters on the original roster — #1–23 (green/red/black slimes, small/big/red bats, skeletons, junior/senior/priest mages, junior/mid/senior guards, orcs, stone golem, crow, white knight, two-handed swordsman, zombie) use the exact stats of the classic 24-floor magic tower handbook, #25–60 follow the original growth curve; a milestone boss in original style guards every 10th floor (Skeleton General → Nether Overlord).
- **Original-style pixel sprites**: one dedicated sprite per monster and per item (`monster_1~60.png`, `item_1~12.png`, 16×16 pixel art ×3), generated by `Assets/generate_monster_sprites.ps1`; preview at [docs/sprites-preview.png](docs/sprites-preview.png). Doors / keys / stairs / shop / NPC / player reuse the classic art; everything is embedded as WPF `Resource`.
- **4-direction player sprite**: `player_up/down/left/right` switch live with movement; no turn on wall bump.
- **Touch-to-fight combat (like the original)**: stepping on a monster starts the fight instantly, resolved turn-by-turn (player first → monster counter → life drain), 260 ms/turn with live HP and a battle log, auto-settled at the end; monsters you cannot break through act as walls.
- **Original damage formula**: player hit = max(1, playerATK − monsterDEF); magic monsters ignore DEF. Estimation and settlement share one formula (`MathHelper`).
- **Monster book (`B`)**: all 60 templates with HP/ATK/DEF/gold/sprite/type plus a live loss estimate and "✓/✗ beatable" verdict.
- **Audio & music**: 8 SFX classes (pickup, fly-orb pickup/launch/arrive, step, door, battle hit, victory, death) plus upbeat explore/battle BGM (C major 112 BPM / A major 150 BPM, seamless 8-bit loops); `M` mutes; everything is synthesized by `generate_audio.ps1`.
- **Save system**: `F5` save / `F9` load (`%LOCALAPPDATA%\Mota100Floors\save.json`, temp file + atomic overwrite).
- **Classic Mota systems**: tiered shops (4 price bands by floor), 5 NPC quests, 6 stat gates, milestone bosses dropping red keys, and the floor-100 win check against the Nether Overlord.
- **Fly Orb (floor shuttle)**: a permanent item at the F1 bottom-left; `I` opens inventory, use it on a stair tile to warp to any visited floor (unvisited floors are greyed out).
- **Original economy**: starting HP 500 / ATK 10 / DEF 10 / yellow key ×1 (start HP calibrated so an optimal full clear of floor 1 costs ≈58% of it), red/blue gems start at +2, red potion +100, HP uncapped; the generator ships with a **playthrough balance simulator** that validates all 100 floors.

## 🚀 Quick Start

Prerequisites: **[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)** (Windows; only needed to build from source — just grab the Release package below to play).

```powershell
# Build (Debug)
dotnet build

# Run directly
dotnet run --project Mota100Floors.csproj

# Publish a self-contained single-file exe for Windows x64 (no .NET required)
dotnet publish -c Release -r win-x64 --self-contained true `
  -p:PublishSingleFile=true -o publish\win-x64
```

> Published output lives in `publish\win-x64\` — double-click `Mota100Floors.exe` to play, no .NET install needed. The single-file exe embeds PNG assets and the runtime; `Data\*.json` and `Assets\Audio\*.wav|*.mp3` ship beside it by design (`ExcludeFromSingleFile` in the csproj), so copy the whole folder when distributing.

## 🎮 Controls

| Key | Function |
|---|---|
| `↑` `↓` `←` `→` / `W` `A` `S` `D` | Move one cell (live sprite direction) |
| `B` | Toggle monster book |
| `I` | Toggle inventory (shows a "Use" action after picking up the Fly Orb) |
| `Esc` | Close teleport panel / inventory / book / shop / dialogs |
| `F5` | Save |
| `F9` | Load |
| `M` | Mute/unmute audio |

Pickups are collected by stepping on them; stepping on a monster opens the battle panel (Boss fights are forced); stairs are map elements you simply stand on. Global keys are locked during combat until the result is confirmed.

## 🧊 Content & Data

- **Monster templates** (`Data/Monsters.json`): 60 templates — #1–23 with the classic 24-floor handbook stats, #24–50 extrapolated along the original curve, #51–60 milestone bosses; `SpriteIndex` maps to the dedicated `monster_{id}.png` sprite, and `IgnoreDefense` mages bypass player DEF in both combat and the book.
- **Floor data** (`Data/Floors/`): generated & validated by the separate `MotaMapGenerator` console project (excluded from the main build via `DefaultItemExcludes`). Regenerate with `dotnet run --project MotaMapGenerator`.
